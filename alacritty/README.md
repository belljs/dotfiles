# Alacritty Config

- Commented out items are generally what I use for Windows. Mac / Linux is everything else UNO.

## MacOS / Linux

- Typically located at: `~/.config/alacritty/alacritty.toml`

## Windows with Native Alacritty

- Typically located at `%APPDATA%\alacritty\alacritty.toml` (common) or the location Alacritty reports in its logs.
